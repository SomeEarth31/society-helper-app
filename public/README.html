Overview

What is Society Helper?

Society Helper connects residents of a housing society with domestic workers — maids, cooks, car washers, caretakers, gardeners, and more. Residents browse available workers, post job listings, track attendance, and pay via UPI. Workers manage their availability, apply for jobs, and track their engagements — all from a phone browser, no installation required.
How It Works

Two sides, one platform

🏠

Residents

  • Browse the worker directory filtered by specialty, availability, and trust score
  • Send hire requests directly to workers you want
  • Post job listings and review applicants
  • Mark daily attendance and view monthly calendars
  • See a live dues summary — days worked × daily rate
  • Pay workers via UPI with one tap — GPay, PhonePe, Paytm all supported
  • View full payment history with UTR references
  • Message workers directly in-app
🧑‍🔧

Workers

  • Set up a profile with specialty, daily rate, and photo
  • Toggle availability on/off from the dashboard
  • Browse the job board and apply with one tap
  • Accept or decline incoming hire requests
  • View active engagements and attendance history
  • Message residents directly in-app

Getting Started

Setup

1

Create a Supabase project

Go to supabase.com, create a project, and copy your project URL and anon key.

2

Run the schema

Open the Supabase SQL editor and paste the contents of supabase/schema.sql. This creates all tables and RLS policies.

3

Enable Phone auth

Under Authentication → Providers, enable Phone. Supabase provides 30 free SMS/day — switch to Twilio or MSG91 later via the same interface.

4

Configure redirect URLs

Under Authentication → URL Configuration, set your Site URL and add https://your-app-*.vercel.app/** to Redirect URLs to cover all preview deployments.

5

Add environment variables

Create a .env.local file in the project root:

NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key

Run locally

npm install
npm run dev

Deploy

Push to master to deploy to production on Vercel. Push to dev or any branch to get an automatic preview deployment.

Authentication

How login works

📱

Login is phone-number OTP only — no passwords to manage. On first login, new users go through an onboarding flow to choose their role (resident or worker) and fill in their details. The app remembers their role and shows the appropriate dashboard every time they return. Sessions are refreshed automatically on every request via Next.js middleware, so users stay logged in without interruption.
